# A.P.J. Abdul Kalam — The People's President

A visually engaging tribute page dedicated to Dr. A.P.J. Abdul Kalam, Indian aerospace scientist, statesman, and the 11th President of India.

This project was created as part of the Oasis Infobyte Web Development Internship (OIBSIP), Level 2 — Task 2.

## 📌 Task Information

- **Internship:** Oasis Infobyte Web Development Internship
- **Track:** Web Development
- **Level:** Level 2
- **Task:** Task 2 — Tribute Page
- **Subject:** Dr. A.P.J. Abdul Kalam

## 📖 Overview

This tribute page presents the life, achievements, and legacy of Dr. A.P.J. Abdul Kalam.

The page covers his early life, education, scientific career, contributions to India's space and missile programmes, presidency, dedication to students, and lasting legacy.

The content has been written and paraphrased for this project rather than copied directly from reference sources.

- 🧑‍🚀 Dedicated hero section featuring A.P.J. Abdul Kalam

- 💬 Distinctive quote section

## 🎨 Design

The page uses a warm editorial design inspired by a magazine-style biography.

### Colour Palette

The design combines:

- Cream background
- Deep navy sections
- Dark blue legacy section
- Marigold/orange accent colour
- Warm neutral text colours

Different backgrounds are used throughout the page to visually separate the biography, timeline, quote, and legacy sections.

## ✍️ Typography

Two different font styles are used:

### Spectral

Used primarily for:

- Main headings
- Hero tagline
- Timeline years
- Quote
- Decorative typography

### Inter

Used primarily for:

- Body text
- Timeline descriptions
- Supporting information
- Footer content

This creates a clear visual distinction between headings and body content.

## 🗓️ Timeline

The timeline highlights major moments in Kalam's life:

|---|---|

## 📱 Responsive Design

The page is designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

On smaller screens:

- The hero section becomes shorter
- Timeline items switch to a single-column layout
- Legacy items stack vertically
- Spacing and typography are adjusted for smaller displays
