- **Project:** Thermal — Temperature Converter

## 📖 Overview

Thermal is a simple and user-friendly temperature converter that allows users to enter a temperature value, select its unit, and convert it into Celsius, Fahrenheit, and Kelvin.

The application includes input validation and handles temperature values below absolute zero with a friendly error message.

## ✨ Features

- 🌡️ Convert between Celsius, Fahrenheit, and Kelvin
- 🔢 Numeric temperature input
- 🔘 Celsius, Fahrenheit, and Kelvin unit selection
- 🔄 Conversion triggered using a Convert button
- 📊 Displays Celsius, Fahrenheit, and Kelvin results simultaneously
- ⚠️ Input validation for empty and invalid values
- ❌ Prevents temperatures below absolute zero
- 🎯 Highlights the selected input unit
- 📱 Responsive design for desktop and mobile screens
- 🎨 Clean and centered user interface
- ✨ Smooth and minimal visual design

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic elements
- **CSS3** — Styling, layout, responsive design, and visual presentation
- **JavaScript** — Temperature conversion, validation, and user interaction
- **Google Fonts** — Sora and Inter

No JavaScript frameworks or external libraries are required.
