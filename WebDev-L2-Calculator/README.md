# Panel — Calculator

A clean, responsive browser-based calculator built using HTML5, CSS3, and Vanilla JavaScript as part of the Oasis Infobyte Web Development Internship (OIBSIP).

## 📌 Task Information

- **Internship:** Oasis Infobyte Web Development Internship
- **Track:** Web Development
- **Level:** Level 2
- **Task:** Task 1 — Calculator
- **Project:** Panel — Calculator

## 📖 Overview

Panel is a fully functional browser-based calculator designed with a clean, modern interface.

It supports basic arithmetic operations, decimal values, operator chaining, clearing the calculator, backspace functionality, division-by-zero protection, and optional keyboard input.

The calculator uses JavaScript event listeners for user interactions and does not use inline `onclick` attributes or `eval()`.

## ✨ Features

- 🔢 Numeric buttons from 0–9
- 🔸 Decimal point support
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Equals button for calculations
- 🧹 Clear button to reset the calculator
- ⌫ Backspace button to remove the last entered character
- 🔗 Operator chaining for sequential calculations
- ⚠️ Division-by-zero error handling
- ⌨️ Keyboard support
- 📱 Responsive layout for smaller screens
- 🎨 Clean and modern calculator interface
- ✨ Active operator highlighting
- 🎯 Keyboard focus styling

## 🛠️ Technologies Used

- **HTML5** — Structure and calculator controls
- **CSS3** — Styling, layout, responsive design, and animations
- **JavaScript (Vanilla)** — Calculator logic and interaction
- **CSS Grid** — Calculator button layout
- **Google Fonts** — Sora and JetBrains Mono

No JavaScript frameworks or external libraries are used.
