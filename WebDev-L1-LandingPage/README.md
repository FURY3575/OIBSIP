# Ridgeline Cycles — Landing Page

A visually polished and responsive static landing page created for the **Oasis Infobyte Web Development Internship — Task 1: Landing Page**.

The project presents **Ridgeline Cycles**, a fictional handcrafted bicycle frame brand based in Salida, Colorado. The design focuses on clean typography, strong visual hierarchy, responsive layouts, and an earthy colour palette.

---

## 📌 Project Overview

Ridgeline Cycles is designed as a premium bicycle brand landing page showcasing its handbuilt steel frames and custom bicycle-building process.

The page provides visitors with information about:

- The brand and its craftsmanship
- The bicycle frame-building process
- The Continental 631 frame
- Frame specifications
- Rider testimonials
- Contact information
- Social media links

---

## ✨ Features

### Navigation
- Sticky navigation bar
- Four navigation links:
  - Process
  - The Frame
  - Stories
  - Contact
- "Book a Fitting" call-to-action button
- Smooth scrolling between sections

### Hero Section
- Large headline introducing the brand
- Supporting description
- Primary "Start Your Build" CTA
- Secondary "See how it's made" link
- Custom inline SVG bicycle illustration

### Process Section
The page presents the bicycle-building process in three stages:

1. Fit consultation
2. Hand-mitred & brazed
3. Paint & delivery

### Frame Specifications
The Continental 631 section includes:

- Reynolds 631 double-butted tubing
- Head tube angle
- Seat tube angle
- Chainstay length
- Bottom bracket drop
- Maximum tire clearance
- Frame weight

### Testimonials
Three rider testimonials are included to provide social proof and demonstrate the experience of using Ridgeline Cycles frames.

### Call-to-Action
A dedicated CTA section encourages visitors to book a fitting.

### Footer
The footer includes:

- Brand information
- Studio links
- Contact email
- Phone number
- Instagram placeholder
- Strava Club placeholder

---

## 🎨 Design

The landing page uses a consistent earthy colour palette built around:

- Warm paper background
- Dark forest green
- Rust/orange accent
- Steel grey
- Dark green typography

The colours are defined using CSS custom properties for consistency throughout the page.

---

## 🔤 Typography

The project uses Google Fonts:

- **Fraunces** — headings and brand typography
- **IBM Plex Sans** — body text and navigation
- **IBM Plex Mono** — technical/specification text

Different font sizes and weights are used to create a clear visual hierarchy between headings, body content, navigation, and technical information.

---

## 📱 Responsive Design

The landing page is designed to work across desktop, tablet, and mobile screen sizes.

Responsive CSS media queries adjust:

- Hero layout
- Content sections
- Process cards
- Frame specification layout
- Testimonials
- Footer
- CTA layout
- Page spacing

CSS Grid and Flexbox are used to create flexible layouts that adapt to smaller screens.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- SVG
- Google Fonts

**JavaScript:** Not used — the task required a static HTML/CSS implementation.
